# 章立て(目次)ステップ 設計

## 目的

OCR確認・修正の後に、スキップ可能な「章立て」ステップを追加する。目次ページのOCR結果から「章名＋開始ページ」を構造化し、PDFのしおり(アウトライン)とEPUBの目次(nav)に埋め込む。画像・テキストを外部へ送信しない方針を守るため、構造化はルールベース＋手動修正で行う(LLM/API利用は対象外)。

## ステップ構成

読み込み / 並べ替え・調整 / OCR確認・修正 / **章立て(スキップ可)** / 詳細＆書き出し

スキップした場合、または章が0件の場合、出力は従来と同一。スキップは既存の章を消さない。

## データモデル

```ts
interface Chapter {
  id: string
  title: string
  pageId: string // 開始ページ。並べ替え・削除に追従するため番号ではなくID
  level: number // 1=章, 2=節。最大2階層
}
```

- IndexedDB に `chapters` を保存(DBバージョンを上げ、既存の移行を壊さない)。
- ページ削除時、その章は次の残存ページへ寄せる(次がなければ直前のページ)。全ページ削除・全削除で章も消す。
- 同一開始ページの複数章を許可する。

## 抽出ロジック(純関数 `src/lib/toc/parseToc.ts`)

入力: 目次ページのOCR行(読み順)、オフセット、ページ一覧。出力: 章候補。

1. 「末尾が数字」の行(`章名 ……… 12`、`第1章 はじめに 12`)を候補にする。全角数字・点線リーダー・ローマ数字に対応。
2. 章名と番号が別行の場合は隣接行を結合する。
3. 「第N章」「N.」「Chapter N」等で level を推定する。判別不能なら level 1。
4. 目次の数字は印刷ページ番号。UIで指定する「本文1ページ目 = 画像○枚目」のオフセットで画像ページへ換算する。既定値は(自動検出時は検出した目次の最終ページの次、手動指定時は指定した目次ページの次)のページ。範囲外は先頭/末尾へクランプする。

## 目次ページの自動検出(純関数 `src/lib/toc/detectTocPages.ts`)

ヒューリスティックによる候補の事前選択。ユーザーが必ず確認・変更できる。

1. 対象範囲は先頭から「全体の30%または40ページの小さい方」までのOCR済みページ(前付けを想定)。
2. ページのスコアは「末尾が数字」の行の割合と件数(点線リーダー付きは加点)、見出しキーワード(目次/もくじ/Contents)の有無(加点)で決める。一定件数(例: 5行)未満のページは0点。
3. 閾値を超えたページが連続していれば1つの目次ブロックにまとめる(複数ページ目次に対応)。
4. 見つからなければ何も選ばず、手動指定に戻す。

## UI

- **目次の読み取り**: ステップを開いたとき、または「目次ページを自動検出」で検出結果を事前選択する。OCR未実施のページが検出範囲にあれば「先頭N枚をOCRすると検出できます」と案内する(全ページOCRは強制しない)。OCR済みページから目次ページを複数指定(検出結果の修正も可)、オフセット入力、「目次を解析」。OCR未実施なら OCR確認ステップへの案内を出す。
- **章の編集リスト**: タイトル、開始ページ(サムネイル付き選択)、階層(章/節)、削除、章を追加。開始ページ順に整列。OCRなしでも手動で作れる。
- **ナビゲーション**: 「スキップ」「次へ」。
- **書き出しパネル**: 章が1件以上のとき「しおり/目次を埋め込む」(既定ON)を表示。

## 書き出し

`exportBook` が `chapters` を書き出し順のページindexへ変換し、Worker へ `{ title, pageIndex, level }[]` として渡す。`buildPdf` / `buildEpub` は index ベースの入力だけを扱う。

- **PDF**: pdf-lib の低レベルAPIで `/Outlines` を構築(入れ子対応、各項目は対象ページへの `/Dest`)。
- **EPUB**: `nav.xhtml` の toc を、`text/page-N.xhtml` へのリンクの入れ子 `<ol>` で生成。章がなければ従来のnav。

## テスト

- 単体: `detectTocPages`(目次ページ・本文ページ・複数ページ目次・目次なし・キーワードあり/なし)、`parseToc`(点線リーダー・全角数字・別行結合・ローマ数字・階層推定)、オフセット換算とクランプ、削除・並べ替え時の章の追従、PDFアウトライン(生成PDFを読み直して `/Outlines` と入れ子を検証)、EPUB nav、`useChapters`、`imageStore` のDB移行。
- コンポーネント: 章立てステップの表示・スキップ・行の追加削除。
- `window.EbookMaker` に章の取得・設定・目次ページ検出・目次解析を追加し、`public/llms.txt` を更新する。

## 対象外

3階層以上、LLMによる構造化、章ごとのEPUB分割。
